# AGENTS.md — локальный шлюз Payload Orchestration (оркестрации Payload)

Scope (область действия): только эта папка и её содержимое.

1. Сначала соблюдай корневой [`AGENTS.md`](../../../AGENTS.md). Этот файл не заменяет корневые правила.
2. Перед любой работой полностью прочитай [`ORCHESTRATOR_RULES.md`](ORCHESTRATOR_RULES.md).
3. Считай [`PROGRESS.md`](PROGRESS.md) единственным оперативным источником состояния этой инициативы.
4. Наличие этих документов не разрешает начинать реализацию Payload CMS (новой системы управления публичным контентом).
5. Не изменяй правила или прогресс в обход описанных протоколов подтверждения, владения файлами, отчётности и независимой проверки.
6. Оркестратор не редактирует файлы и не выполняет технические проверки лично; он назначает отдельные ограниченные задания агентам.
7. При конфликте соблюдай системные и developer-инструкции (инструкции разработчика), затем корневой `AGENTS.md`, затем этот локальный файл и остальные документы папки.
