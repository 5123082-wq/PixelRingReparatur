## Acceptance Criteria (критерии приёмки)

Каждый критерий должен быть наблюдаемым и проверяемым.

## Required Verification (обязательная проверка)

Указать команды, маршруты, данные, размеры viewport (окна браузера), ожидаемые артефакты и обязательные независимые роли. Исполнитель не принимает собственную работу.

## Expected Artifacts (ожидаемые артефакты)

Перечислить файлы, отчёты, снимки экрана, экспорт или другие проверяемые результаты. Не включать значения секретов.

## Required Report (обязательный отчёт)

Исполнитель использует [`WORKER_REPORT_TEMPLATE.md`](WORKER_REPORT_TEMPLATE.md) и указывает точные пути, команды и результаты. Формулировка «всё работает» без доказательств запрещена.

## Stop Conditions (условия остановки)

Агент обязан немедленно остановиться и сообщить оркестратору при обнаружении изменения scope (границ задачи), секрета, production connection (подключения к рабочему окружению), destructive action (разрушительного действия), пересечения файлов, неясного целевого окружения или необходимости миграции без отдельного подтверждения владельца.

При необходимости изменить файл вне `Allowed Files` (разрешённых файлов) агент не делает изменение и запрашивает новый или расширенный task packet (пакет задания).
