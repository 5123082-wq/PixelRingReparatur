# Illuminated valance calculator fonts

The calculator self-hosts the exact files listed below. They were retrieved
from the official [Google Fonts repository](https://github.com/google/fonts) at
commit `389b770410cc0b7c21c85673bfa2077420fe7f65` on 2026-07-17.

All ten families are licensed under the SIL Open Font License 1.1. The exact
license text supplied with each family is retained in the `licenses/` folder.
The repository metadata for every selected family declares both Latin and
Cyrillic support.

| Family | Local file | Upstream directory | License copy |
| --- | --- | --- | --- |
| Montserrat | `montserrat-variable.ttf` | `ofl/montserrat` | `licenses/montserrat-OFL.txt` |
| Open Sans | `open-sans-variable.ttf` | `ofl/opensans` | `licenses/opensans-OFL.txt` |
| Oswald | `oswald-variable.ttf` | `ofl/oswald` | `licenses/oswald-OFL.txt` |
| PT Sans | `pt-sans-regular.ttf` | `ofl/ptsans` | `licenses/ptsans-OFL.txt` |
| Playfair Display | `playfair-display-variable.ttf` | `ofl/playfairdisplay` | `licenses/playfairdisplay-OFL.txt` |
| Rubik | `rubik-variable.ttf` | `ofl/rubik` | `licenses/rubik-OFL.txt` |
| Fira Sans | `fira-sans-regular.ttf` | `ofl/firasans` | `licenses/firasans-OFL.txt` |
| Merriweather | `merriweather-variable.ttf` | `ofl/merriweather` | `licenses/merriweather-OFL.txt` |
| Source Sans 3 | `source-sans-3-variable.ttf` | `ofl/sourcesans3` | `licenses/sourcesans3-OFL.txt` |
| Roboto | `roboto-variable.ttf` | `ofl/roboto` | `licenses/roboto-OFL.txt` |

These files are used at weight 400 only. A font choice changes measured
geometry; it is not treated as a price-complexity factor.
